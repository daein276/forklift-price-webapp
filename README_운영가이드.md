# 중고지게차 시세 공유 시스템 — 운영 가이드

이 문서는 개발 지식이 없어도 시스템을 배포·운영할 수 있도록 순서대로 정리한 안내서입니다.
막히는 부분은 그대로 캡처해서 저(Claude)에게 물어보시면 됩니다.

## 이 시스템의 구조 (한눈에)
- **화면(웹사이트)**: Streamlit Community Cloud라는 무료 서비스가 띄워줍니다.
- **코드**: GitHub이라는 곳에 저장해두면 Streamlit이 그걸 읽어서 웹사이트로 만들어줍니다.
- **데이터(가격 목록)**: Google Sheets(구글 시트) 한 장에 전부 저장됩니다. 문제가 생기면
  이 시트를 직접 열어서 눈으로 확인/수정할 수 있습니다.
- **로그인 계정**: 코드에는 없고 Streamlit Cloud의 "Secrets"라는 비공개 저장소에만 있습니다.

## 1단계. 계정 만들기 (직접 클릭이 필요해서 대표님이 하셔야 합니다)
1. **GitHub 계정**: https://github.com 에서 무료 가입
2. **Streamlit Community Cloud 계정**: https://streamlit.io/cloud 에서 "Sign up" →
   GitHub 계정으로 로그인
3. **Google Cloud 서비스 계정** (구글 시트 접근용):
   1. https://console.cloud.google.com 접속 (평소 쓰시는 구글 계정으로 로그인)
   2. 새 프로젝트 생성 (이름 아무거나, 예: `daein-forklift`)
   3. 좌측 메뉴 "API 및 서비스" → "라이브러리" → "Google Sheets API" 검색 → 사용 설정
   4. "API 및 서비스" → "사용자 인증 정보" → "사용자 인증 정보 만들기" → "서비스 계정"
   5. 서비스 계정 이름 아무거나 입력하고 만들기 완료
   6. 만들어진 서비스 계정 클릭 → "키" 탭 → "키 추가" → "새 키 만들기" → JSON 선택 →
      다운로드됨 (이 JSON 파일 내용을 나중에 secrets에 붙여넣습니다. **외부에 유출되면 안 되는 파일**)
   7. 서비스 계정 이메일 주소를 복사해두세요 (예: `xxxx@daein-forklift.iam.gserviceaccount.com`)

이 3가지가 준비되면 저에게 알려주세요. 나머지(코드 올리기, 시트 만들기, 배포)는 함께 진행하면 됩니다.

## 2단계. Google Sheet 만들기
1. https://sheets.google.com 에서 새 시트 생성, 이름 예: `대인리프트_지게차시세`
2. 오른쪽 위 "공유" 버튼 → 위에서 복사한 서비스 계정 이메일을 추가하고 **"편집자"** 권한 부여
3. 주소창 URL에서 `/d/`와 `/edit` 사이의 긴 문자열이 "시트 ID"입니다. 이걸 secrets의
   `sheet_id` 값으로 사용합니다.
4. 시트 안의 탭(표준리스트, 확인필요)은 프로그램이 처음 접속할 때 자동으로 만들어줍니다.
   미리 만들 필요 없습니다.

## 3단계. secrets 채우기
`.streamlit/secrets.toml.example` 파일을 열어보고 그대로 값만 채우면 됩니다.
- `sheet_id`: 2단계에서 구한 시트 ID
- `[gcp_service_account]`: 1단계에서 다운받은 JSON 파일을 열어서 그대로 옮겨 적기
  (JSON의 `private_key` 값 안에 있는 줄바꿈은 `\n` 그대로 두면 됩니다)
- `[users.아이디]`: 로그인 계정. 새 업체를 추가할 때마다 이런 블록을 하나씩 추가

**로컬에서 테스트하려면** `secrets.toml.example`을 복사해서 `.streamlit/secrets.toml`로
저장하고 값을 채우세요. 이 파일은 `.gitignore`에 등록되어 있어서 GitHub에는 올라가지 않습니다.

## 4단계. 새 협력업체 계정 추가하기
로그인 비밀번호는 평문이 아니라 암호화된 값(해시)으로 저장해야 합니다. 저에게
"○○업체 계정 하나 추가해줘, 아이디는 ○○, 비밀번호는 ○○로 해줘"라고 요청하시면
해시값을 만들어서 `secrets.toml.example`(또는 Streamlit Cloud의 Secrets 설정)에
추가하는 것까지 도와드리겠습니다. 추가 후 협력업체에게 아이디/비밀번호를 알려주시면 됩니다.

## 5단계. 배포
1. GitHub에 새 저장소 생성 (Private로 설정 가능)
2. `webapp` 폴더 안의 파일들을 그 저장소에 업로드 (`secrets.toml`은 절대 올리지 않음 —
   `.gitignore`가 자동으로 막아줍니다)
3. https://share.streamlit.io 에서 "New app" → 방금 만든 저장소 선택 →
   Main file path에 `app.py` 입력 → Deploy
4. 배포 후 "Settings" → "Secrets"에 3단계에서 채운 secrets 내용을 그대로 붙여넣기
5. 잠시 후 `https://프로젝트이름.streamlit.app` 같은 주소가 생기며, 이 주소를 협력업체에
   공유하면 됩니다.

## 코드를 수정했을 때 (재배포)
GitHub 저장소에 새 파일을 올리기만 하면 Streamlit Cloud가 자동으로 몇 분 안에
다시 배포합니다. 따로 버튼을 누를 필요는 없습니다.

## 문제가 생겼을 때 확인할 것
- **로그인이 안 됨**: Streamlit Cloud의 Secrets에 `[users.아이디]` 블록이 정확히
  들어있는지 확인
- **업로드했는데 시세검색에 안 보임**: Google Sheet를 직접 열어서 `표준리스트` 탭에
  데이터가 실제로 들어갔는지 확인. 안 들어갔다면 서비스 계정에 "편집자" 권한이
  제대로 공유되어 있는지 확인
- **"확인필요" 항목이 많음**: 해당 업체의 리스트 양식이 기존 5개 업체(노블리프트/롯데렌탈/
  서현/항도/디피엘)와 형식이 달라서 자동 인식이 안 된 경우입니다. 원문 샘플을 저에게
  보여주시면 인식 규칙을 추가하겠습니다.
- **화면이 하얗게 뜨거나 에러가 남**: Streamlit Cloud 앱 페이지의 "Manage app" →
  로그(Logs)를 캡처해서 저에게 보내주세요.
